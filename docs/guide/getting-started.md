# Getting Started

`@cc-heart/utils` is a library of JavaScript common tools — the environment-agnostic core of the utils family.

## Install

```shell
npm install @cc-heart/utils
# or
pnpm add @cc-heart/utils
```

## Usage

```js
import { capitalize } from '@cc-heart/utils'

capitalize('string') // String
```

## What's inside

- **string** — `capitalize`, `unCapitalize`, ...
- **date** — date formatting helpers
- **random** — random number / string generators
- **validate** — type & value validators
- **promise** — async helpers (`retry`, `withTimeout`, ...)
- **request** — fetch-based HTTP client, see the [Request guide](/guide/request)
- **sse** — Server-Sent Events, see the [SSE guide](/guide/sse)
